│                       ⚙️  CORE FEATURES IMPLEMENTED                             │
├─────────────────────────────────────────────────────────────────────────────────┤
│                                                                                 │
│  🔹 Receipt Number Generation                                                  │
│     Format: BRN01-20260215-0001                                                │
│     • Branch code                                                              │
│     • Date (YYYYMMDD)                                                          │
│     • Sequential number                                                        │
│     • Automatic & unique per day per branch                                    │
│                                                                                 │
│  🔹 Advance Amount Calculation                                                 │
│     Formula: SUM(net_weight × rate_per_karat) × interest_percentage / 100      │
│     • Fetches karat rates from database                                        │
│     • Supports custom interest percentage                                      │
│     • Rounds to 2 decimal places                                               │
│                                                                                 │
│  🔹 Due Date Calculation                                                       │
│     • Add months based on pawning period (3/6/12)                              │
│     • Automatic date arithmetic                                                │
│     • Returns YYYY-MM-DD format                                                │
│                                                                                 │
│  🔹 Gold Articles Validation                                                   │
│     • Maximum: 5 articles per ticket                                           │
│     • Weight consistency: net_weight ≤ gross_weight                            │
│     • Valid karats: 8, 10, 12, 14, 16, 18, 20, 22, 24                          │
│     • Quantity must be ≥ 1                                                     │
│     • All weights must be > 0                                                  │
│                                                                                 │
│  🔹 Minimum Loan Validation                                                    │
│     • Minimum advance amount: 5,000 Rs.                                        │
│     • Enforced on all tickets                                                  │
│                                                                                 │
│  🔹 Business Rule Validation                                                   │
│     • Customer must exist and be ACTIVE                                        │
│     • Branch must exist and be ACTIVE                                          │
│     • Staff creator must exist and be ACTIVE                                   │
│     • Pawning period must be valid (3/6/12 months)                             │
│                                                                                 │
│  🔹 Transaction Management                                                     │
│     • BEGIN TRANSACTION                                                        │
│     • Insert multiple related records                                          │
│     • COMMIT if all succeed                                                    │
│     • ROLLBACK if any error                                                    │
│                                                                                 │
│  🔹 Activity Logging                                                           │
│     • Insert into activity_logs table                                          │
│     • Track: user, role, branch, action, entity, description                   │
│     • Timestamp automatic (CURRENT_TIMESTAMP)                                  │
│                                                                                 │
│  🔹 Status History Tracking                                                    │
│     • Insert into ticket_status_history                                        │
│     • Record initial status change                                             │
│     • Can track all status changes lifetime                                    │
│                                                                                 │
